WebG850

シャープ PC-G850V / PC-G850VS 互換 BASIC の Web エミュレータ

ここは LCD への直接入力の補助（コピペ用）です。書いたら「取り込む」でプログラムへ反映し、 操作バーの RUN で実行してください。

本エミュレータは ROM イメージを一切同梱・配布しない独立実装です。 文字の字形（フォント）も ROM から吸い出さず、自作しています。

This is a clean-room implementation: it does not include, distribute, or reference any ROM image.

現在は Phase 1（互換 BASIC インタプリタ）の段階です。未実装の命令に 実行が到達すると ?UNSUPPORTED と表示して停止します。動かない作品があれば ぜひご報告ください。

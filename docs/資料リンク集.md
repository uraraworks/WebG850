# PC-G850 資料リンク集

調査日：2026-08-14

## 最重要：技術解析資料

### [SHARP PC-G850 解析資料 — akiyan.com](https://www.akiyan.com/pc-g850_technical_data)

**この 1 ページが実装の背骨になる。** 収録内容：

- **BIOS ルーチン仕様表**（ルーチン名／アドレス／破壊レジスタ／内容／引数／返り値）
  - `BE62h` 文字出力 / `BFEEh` 文字連続出力 / `BFF1h` 文字列出力
  - `BFD0h` グラフィック出力 / `BE53h` リアルタイムキー入力 / `BCFDh` ウェイトキー入力
- **BIOS キー入力 値対応表**
- **I/O ポート** — 表示制御（`40h` 出力：LCD 電圧・コントラスト・表示方法）、
  キーマトリクス（`11h`・`12h` 出力、`10h` 入力）
- **VRAM 表示開始位置**（`790Dh` の下位 4 ビット。値を 8 倍したものが実際のドット数）
  - 隠し 16 ドット領域を使った高速スクロールの仕組みも詳述されている
- **ワークエリア** — コントラスト `779Ch` / CAPS・カナロック `7901h` / INKEY `7966h`・`7E00h`
- **BEEP 命令仕様**（周波数・長さ指定）
- **BASIC 中間コード表** ← テキスト ⇄ 内部形式の変換に必須
- 検品モード、ファイル形式

※ 記載は G850／G850S ベース。「G850S の中間コード表は G850 と大差無いと思われる」との注記あり。

### 系譜に入らないもの（票にならない）— ver0 氏の互換 BASIC

**上表とは別枠。** g800 は ROM を実行するエミュレータだが、ver0 氏の互換 BASIC は
**ROM を一切実行しない別実装**であり、性質が正反対。同じ「ver0氏」という作者つながりで
系譜Aの1つに数えると、「g800 と互換 BASIC で照合した」がまるで独立2票のように読めてしまう
（実際は作者内の異なる2実装を見ただけ）ので、ここでは分離する。

`spec/SCHEMA.md` の `verified_by: emulator_compat`（原則不採用。他人の推測を写すため）に
対応する区分で、答え合わせの参考にはするが票としては数えない。

| 名前 | 対応 | 実装 | URL |
|---|---|---|---|
| **ver0 氏の互換 BASIC** | PC-G850V | C。**ROM 不要のゼロから再実装** | http://ver0.sakura.ne.jp/pc/index.html#g800 |

**ver0 氏の互換 BASIC の設計方針**（本人の記述）：

> IOCS コールのエミュレーションと既存 BASIC インタプリタを活用しているため、
> ROM イメージなしでも一部のポケコンプログラム実行が可能

→ 我々が採る構成（自前 BASIC ＋ BIOS コールのエミュレーション）と同じ。
「一部の」とあるので**完全ではなく、伸びしろがある**。

**webg850 の存在は企画の前提を崩さない。** ROM必須・ローカルFirefox・公開URLなしで、
「ブラウザを開くだけで動く」枠は空いたまま。むしろ「ユーザーが自分の実機から吸い出したROMを
持ち込む」設計の先例として、Phase 2（Z80コア）の逃げ道に使える。

**MAME に G850 ドライバは見つからなかった。** 検索で出てくる sharpemu / sc61860emu / pc1500 系は
**別CPU（SC61860）の旧機種向けで、Z80 の G850 とは無関係。**
